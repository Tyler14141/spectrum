# spectrum

Minimal Node.js starter for the Spectrum project.

## Requirements

- Node.js 20+
- npm 10+

## Getting Started

```bash
npm install
```

## Scripts

- `npm run start`: Run the app.
- `npm run dev`: Run the app in development mode.
- `npm run test`: Placeholder test command.
